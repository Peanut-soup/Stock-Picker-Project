MATLAB NASDAQ-100 Algorithmic Trading Strategy
What This Project Does
I built this MATLAB project as a final project for my high school computer science class, where it won first place in our classroom programming competition.

The program is a historical simulation tool designed to test a trading strategy using past stock market data from the NASDAQ-100 index. Starting with a mock $10,000 budget, the algorithm analyzes a specific period of historical data to determine exactly when it should have bought and sold assets, and how many shares it would have purchased.

The goal of the competition was to see whose algorithm would make the most money if it had actually been running live during that past time period. My strategy generated the highest return in the class to take first place.

Project Status Note: This code was fully functional and successful when run in class. Because MATLAB Online updates automatically, changes to their built-in table libraries over the last two years mean the external tickers function currently throws an error. However, the core logic, trading loops, and strategy math are still fully visible to show how the winning program worked.

Guide to the Files
RunStockTool.m: The main script that executes the trading strategy and runs the historical simulation.

processTransactions.m & createTransactionTable.m: The backend logic that takes raw transaction logs and formats them into readable MATLAB data tables.

calcEMA.m: The script that calculates Exponential Moving Averages to help the algorithm decide when a stock trend is moving up or down based on past data.

NASDAQ100.txt: The target list of top-tier stocks used by the algorithm.

NVDA.png: A chart generated by the program showing the trading results and performance from the original winning run.

Computer Science Concepts Used
Data Management: Learning how to import .csv files and raw text logs (NASDAQ100.txt) into organized MATLAB data tables.

Algorithmic Decision Making: Using for loops, arrays, and conditional if/else statements to automate buy/sell triggers and calculate position sizes based on a budget.

Applied Math: Programming mathematical formulas (like moving averages and budget allocation math) to execute calculations automatically based on data inputs.
